# citrine-gb-blip

Band-limited sound synthesis for the Game Boy sound chip in [citrine-gb](https://crates.io/crates/citrine-gb). It is a fork of [blip_buf](https://crates.io/crates/blip_buf) 0.1.6 by Mathijs van de Nes: the output is the same, with fewer bounds checks and one buffer for all channels.

The MIT licence of the original blip_buf code is in `LICENSE`.
