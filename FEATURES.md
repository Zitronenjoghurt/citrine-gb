# Features

- Full Game Boy video and audio
- Support for Windows, MacOS, Linux and Web
- Touch layout for phones, with on-screen controls that can be resized, faded, mirrored or hidden
- Controller support, including on the web
- Remappable keyboard and controller bindings
- Plays Game Boy games with MBC1, MBC2, MBC3 (no RTC yet) and MBC5 cartridges
- (M-)Cycle-accurate instruction and memory timing
- Automatic battery saves, plus unlimited named snapshot slots per game with quick save/load
- Custom screen palettes with short share codes
- Screenshots
- Includes bundled open source homebrew games
- Debugging tools: disassembly with breakpoints, register/APU inspection, state dumps, input recording
