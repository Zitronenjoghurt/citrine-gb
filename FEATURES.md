# Features

- Full Game Boy and Game Boy Color video and audio
- Support for Windows, MacOS, Linux and Web
- MBC1, MBC2, MBC3 with real-time clock and MBC5 cartridges
- (M-)Cycle-accurate instruction and memory timing
- Bundled open source homebrew games, and real game names from MAME's game list
- Touch layout for phones with adjustable on-screen controls
- Controller support, including on the web
- Remappable keys, controller buttons and shortcuts
- Battery saves other emulators can read, and unlimited named snapshots per game
- Autosaves on a timer, on close and after a crash
- .sav import and export, including RetroArch's .srm and .rtc with the game's clock
- Local link cable between two games side by side
- Event partner that trades official event Pokémon to your game
- Online play with friends through a relay server which also enables cloud saves
- End-to-end encrypted chat with screenshots, recordings and replays
- Encrypted relay connections and two-factor sign-in
- Pokémon save viewer for Red to Crystal: party, boxes, bag and Pokédex
- Play time stats per day, week, month, year and game
- Discord Rich Presence on desktop
- Custom screen palettes with short share codes
- Game Boy Color palettes for original Game Boy games
- Screen scaling, ghosting, a matrix grid overlay and UI themes
- Tabs you can split or pop out into windows, and a focus mode for only the screen
- Screenshots and recordings
- Export, import or delete everything the app keeps on a device
- Debugger with disassembly, breakpoints, stepping, APU inspection and input recording
