# Features

- Full Game Boy video and audio
- Game Boy Color support, picked from the cartridge header or set in Settings
- Support for Windows, MacOS, Linux and Web
- Touch layout for phones, with on-screen controls that can be resized, faded, mirrored or hidden
- Controller support, including on the web
- Remappable keyboard and controller bindings
- Plays Game Boy games with MBC1, MBC2, MBC3 (with real-time clock) and MBC5 cartridges
- (M-)Cycle-accurate instruction and memory timing
- Automatic battery saves that other emulators can read, plus unlimited named snapshot slots per game
  with quick save/load
- Autosaves on a timer, on close and after a crash, kept apart from your own snapshots
- Imports and exports .sav files, and the .srm and .rtc pair from SameBoy in RetroArch, with the
  game's clock
- Custom screen palettes with short share codes
- The Game Boy Color's palettes for original Game Boy games, and colours softened like its screen
- Screenshots, and video recordings with sound saved as MP4
- Includes bundled open source homebrew games
- Debugging tools: disassembly with breakpoints, register/APU inspection, state dumps, input recording
