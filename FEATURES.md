# Features

- Full Game Boy and Game Boy color video and audio
- Support for Windows, MacOS, Linux and Web
- Plays Game Boy games with MBC1, MBC2, MBC3 (with real-time clock) and MBC5 cartridges
- (M-)Cycle-accurate instruction and memory timing
- Includes bundled open source homebrew games, and shows real game names from MAME's game list
- Touch layout for phones, with on-screen controls that can be resized, faded, mirrored or hidden
- Controller support, including on the web
- Remappable keyboard and controller bindings and shortcuts
- Automatic battery saves that other emulators can read, plus unlimited named snapshot slots per game
  with quick save/load
- Autosaves on a timer, on close and after a crash, kept apart from your own snapshots
- Imports and exports .sav files, and the .srm and .rtc pair from SameBoy in RetroArch, with the
  game's clock
- Link cable between two games side by side, to trade between your own games, with shared or split
  controls
- Event partner that trades official event Pokémon to your game
- Online play with friends through a relay server which also enables claude saves
- End-to-end encrypted chat with read receipts, emoji, and screenshots, recordings and replays to send
- Party, boxes, bag and Pokédex from the save in Pokémon Red, Blue, Yellow, Gold, Silver and Crystal
- Play time stats per day, week, month, year and game
- Discord rich presence for the game you play (desktop, off by default)
- Custom screen palettes with short share codes
- The Game Boy Color's palettes for original Game Boy games, and colours softened like its screen
- Screen scaling, ghosting, a matrix grid overlay and UI themes
- Tabs you can split or pop out into windows, and a focus mode for only the screen
- Screenshots, and video recordings with sound saved as MP4
- Export, import or delete everything the app keeps on a device
- Debugging tools: disassembly with breakpoints, stepping, register/APU inspection, state dumps, input recording
